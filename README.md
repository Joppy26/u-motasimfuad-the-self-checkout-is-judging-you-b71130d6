## What it does

A deterministic program that writes one original funny remark from a judgmental self-checkout machine to `/output/entry.txt` — the sort of line the till would say to a shopper buying twelve yoghurts and no vegetables. No randomness, no network, no model calls.

## Run

```sh
node main.ts
```

Then read `/output/entry.txt`.
